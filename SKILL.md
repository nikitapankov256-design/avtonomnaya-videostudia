# Навык: Автономная видеостудия (строго бесплатно)

## Назначение
Преобразовывать тему из `content/topic.txt` в вертикальный MP4-ролик на русском языке без платных API и без ручного монтажа.

## Жёсткие правила
- Никаких платных подписок, платных API и платных генераторов.
- Не публиковать ролик и не заявлять о публикации без действующего OAuth-доступа и подтверждения платформы.
- Не использовать чужую музыку/видео без разрешения.
- Не выдумывать цены, адреса, отзывы, характеристики и обещания.
- Сначала проверять, что итоговый MP4 существует и воспроизводим.
- Если нет ключей или разрешений, создавать видеофайл и явно отмечать, что публикация заблокирована настройкой доступа.

## Конвейер
1. Прочитать тему из `content/topic.txt`.
2. Сформировать короткий сценарий по шаблону в `build_video.py`.
3. Создать титульные карточки и русскую озвучку через бесплатный системный TTS `espeak-ng`.
4. Собрать вертикальное видео через FFmpeg.
5. Проверить файл и сохранить его как артефакт GitHub Actions.

## Ограничения
Этот проект автоматизирует создание ролика в GitHub Actions. Он сам по себе не создаёт GitHub-репозиторий, не получает пользовательские OAuth-разрешения и не публикует на YouTube/Instagram без отдельно настроенных секретов и разрешений.
