# Бесплатная автономная видеостудия

Проект собирает вертикальный рисованный мультфильм 720×1280: автомобиль и механик ведут диалог, по очереди говорят двумя русскими голосами Piper; показываются проверка ходовой, развал, схождение, кастер, 3D-стенд и контроль результата.

В ролике не используются названия компаний, логотипы, адреса, телефоны, цены или рекламные обещания.

## Запуск
Откройте Actions → «Собрать рисованный мультфильм» → Run workflow. Готовый MP4 появится в Artifacts завершённого запуска.

## Изменить тему
Отредактируйте массив SCENES в build_video.py или content/topic.txt. Для новой темы сценарий в SCENES нужно обновить отдельно.

## Бесплатные компоненты
Сборка использует GitHub Actions, FFmpeg, Pillow и русскую модель Piper ru_RU-irina-medium. Озвучка синтезированная двумя разными нейроголосами; это не запись живых актёров. Бесплатность зависит от квоты GitHub Actions аккаунта.
