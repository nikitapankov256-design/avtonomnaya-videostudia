# Автономная видеостудия — бесплатный старт

Проект создаёт простой вертикальный ролик 1080×1920 с русскими титрами и синтезированной речью. Визуал — аккуратные текстовые карточки, без выдуманных фотографий и отзывов.

## Запуск
- На GitHub загрузить содержимое архива в новый репозиторий.
- Открыть вкладку **Actions** и запустить workflow **Собрать ролик**.
- Готовый MP4 появится в Artifacts у завершённого запуска.

## Изменить тему
Отредактировать `content/topic.txt`.

## Важно
Рендеринг бесплатен в пределах доступной квоты GitHub Actions. Создание репозитория, первоначальная загрузка файлов и выдача разрешений на публикацию требуют действий владельца аккаунта. Публикация не включена: без OAuth-токенов нельзя безопасно публиковать от имени пользователя.
