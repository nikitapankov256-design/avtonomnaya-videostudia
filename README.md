# Бесплатная автономная видеостудия

Проект собирает вертикальный рисованный мультфильм 720×1280 в закреплённом стиле референса: выразительные мультперсонажи с движением и мимикой, многослойные декорации мастерской, свет, частицы, анимированные технические схемы и крупные титры. Содержание и последовательность объяснения остаются прежними.  автомобиль и механик ведут диалог, по очереди говорят двумя русскими нейроголосами Microsoft Edge TTS; показываются проверка ходовой, развал, схождение, кастер, 3D-стенд и контроль результата.

В ролике не используются названия компаний, логотипы, адреса, телефоны, цены или рекламные обещания.

## Запуск
Откройте Actions → «Собрать рисованный мультфильм» → Run workflow. Готовый MP4 появится в Artifacts завершённого запуска.

## Изменить тему
Отредактируйте массив SCENES в build_video.py или content/topic.txt. Для новой темы сценарий в SCENES нужно обновить отдельно.

## Бесплатные компоненты
Сборка использует GitHub Actions, FFmpeg, Pillow и бесплатный пакет edge-tts для синтеза русской речи. Озвучка синтезированная двумя разными русскими голосами — женским и мужским; это не запись живых актёров. Анимация персонажей включает движение корпуса, вращение колёс, жесты механика и синхронную смену рта. Бесплатность зависит от квоты GitHub Actions аккаунта.
