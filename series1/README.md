# «За закрытой дверью» — серия 1

Автоматическая сборка вертикального MP4 (720×1280) в GitHub Actions.

## Запуск
1. Откройте вкладку **Actions** в репозитории.
2. Выберите workflow **«Собрать За закрытой дверью — серия 1»**.
3. Нажмите **Run workflow** → **Run workflow**.
4. Дождитесь завершения сборки.
5. Откройте запуск и скачайте артефакт **za-zakrytoy-dveryu-episode-01**.

## Что используется
- Python + Pillow — рисованные сцены.
- edge-tts — синтез русской речи (нужен доступ к интернету во время сборки).
- FFmpeg — движение камеры и кодирование MP4.
- GitHub Actions — бесплатная облачная сборка в пределах квот аккаунта.

Это motion-comic: иллюстрированные сцены с плавным приближением, диалогами и озвучкой, а не покадровая рисованная анимация.
