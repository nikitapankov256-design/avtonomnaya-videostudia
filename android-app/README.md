# AI Video Studio для Android

Нативное Android-приложение для генерации настоящего видео по текстовой теме через облачную модель Kling Video 3 Standard на fal.ai.

## Что реализовано в первой сборке
- Русский интерфейс.
- Ввод темы и автоматическое добавление кинематографического описания.
- Выбор формата 9:16, 16:9 или 1:1.
- Выбор длительности 5, 10 или 15 секунд.
- Отправка задачи в очередь fal.ai, отслеживание статуса и получение результата.
- Автоматическое сохранение MP4 в Movies через Android Download Manager.

## Сборка APK
Каждое изменение в `android-app/**` запускает GitHub Actions. Успешная сборка публикует artifact `ai-video-studio-apk` с APK-файлом.

## Использование
Для реальной генерации нужен личный API-ключ fal.ai. Получить его можно в кабинете fal.ai. Ключ вводится в приложении и не помещается в репозиторий. Генерация платная по тарифам fal.ai; бесплатный безлимит не обещается.

## Ограничения первой версии
- Это первая рабочая интеграция text-to-video, а не полный монтажный пакет.
- Для Kling V3 нативная генерация речи поддерживает китайский и английский; поэтому в первой версии аудио генерации выключено, чтобы не выдавать английскую речь за русскую.
- Русская озвучка, сценарная разбивка на сцены, диалоги, фото-анимация и монтаж нескольких клипов остаются следующими этапами.
- API-ключ передаётся непосредственно из приложения в fal.ai. Для публичного распространения безопаснее добавить собственный серверный proxy; не используй один общий ключ, встроенный в APK.
- Модель, её доступность, цена и ограничения определяются fal.ai и могут меняться.
