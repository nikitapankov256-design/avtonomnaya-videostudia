# AI Video Studio для Android

Бесплатный офлайн-монтажёр для Android. В этой ветке облачная генерация через fal.ai удалена: приложение больше не требует API-ключей, регистрации, подписок или интернет-соединения для монтажа.

## Реализовано в версии 0.2.0
- Импорт нескольких видеофайлов через системный выбор файлов Android.
- Объединение выбранных клипов в один MP4 на устройстве через AndroidX Media3 Transformer.
- Три режима порядка клипов: исходный, обратный и случайный.
- Необязательная фоновая аудиодорожка с повторением до конца видеоряда.
- Сохранение результата в приватную папку приложения Movies.
- Нет искусственного ограничения длительности ролика в интерфейсе. Фактический предел зависит от размера исходников, свободного места, кодеков и производительности телефона.

## Сборка APK
Изменения в `android-app/**` запускают GitHub Actions. Успешная сборка публикует artifact `ai-video-studio-apk`.

## Что пока НЕ реализовано
Это первый локальный монтажный движок, а не законченный профессиональный редактор и не генератор видео по одной теме. Пока отсутствуют таймлайн с обрезкой, переходы и кроссфейды, цветокоррекция, фильтры, титры и субтитры, наложение нескольких видеодорожек, автоматический сценарий, генерация новых AI-сцен, русская озвучка и синхронизация губ. Не следует считать три режима порядка клипов всеми возможными стилями монтажа.

## Почему бесплатность здесь реальна
Монтаж выполняется локально средствами AndroidX Media3 и не обращается к платному API. Само приложение не берёт оплату за экспорт. Для будущей генерации реалистичных AI-видеосцен на телефоне потребуются отдельные локальные модели; их качество и скорость будут ограничены аппаратными возможностями устройства и размером моделей.
